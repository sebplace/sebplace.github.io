Jouw eerste commit

Het meest beginner-proof pad van “ik code niet” naar “mijn code staat op GitHub” — met GitHub Copilot als gids, niet met rauwe git-syntax uit het hoofd.

Geen kredietkaart. Geen lokale git-commando’s voor het vlaggenschippad. Start in de browser en kies daarna de route die bij je comfortniveau past.

Als deze eerste test al groter voelt dan één repository, doe de diagnose in 2 minuten om de nuttigste institutionele volgende pagina te kiezen.

1. Maak je GitHub-account aan ↗ bron

Begin op github.com/signup. Een geverifieerd e-mailadres is nodig vóór je een repository kunt maken, en 2FA meteen daarna inschakelen is de slimme volgende stap.

⚡

Start in 30 seconden ↗ bron

Ga naar github.com/signup en maak je account aan. Aanmelden met Google of Apple wordt ondersteund.

✉️

Verifieer je e-mail ↗ bron

GitHub vraagt een geverifieerd e-mailadres vóór je je eerste repository kunt aanmaken.

🔐

Schakel daarna 2FA in ↗ bron

Doe dat meteen na je registratie zodat je nieuwe account vanaf dag één goed beveiligd is.

2. Maak je eerste repository aan in de browser ↗ bron

Dit is het pad zonder installatie en de vriendelijkste manier om te voelen wat een repository is voordat je tools hoeft aan te raken.

01

Klik op het + icoon ↗ bron

Open rechtsboven op GitHub het + menu en kies New repository.

02

Geef hem een korte naam ↗ bron

Kies iets eenvoudigs en onthoudbaars zoals hello-world, quiz-demo of campus-faq.

03

Kies de zichtbaarheid ↗ bron

Public is prima voor een demo; private is prima voor een intern experiment.

04

Zet Add README aan ↗ bron

Zo wordt de repository meteen met één bestand aangemaakt, zodat je onmiddellijk een eerste wijziging kunt doen.

05

Maak de repository aan ↗ bron

Klik op Create repository en klaar: GitHub heeft net je eerste projectruimte gemaakt.

3. Kies hoe Copilot je helpt om code naar GitHub te pushen

Er is niet één “juist” beginpad. Neem de route die vandaag het best past bij jouw vertrouwen.

🌐

Best voor totale beginners

Ik begin volledig in de browser ↗ bron ↗ bron

Docenten, HR, financiën, administratie, supportteams

Nul installatie. Copilot kan de code schrijven, de pull request openen, de branch bijwerken en jou laten mergen zonder lokale git-commando’s.

  1. Open of maak een kleine issue in de repository, bijvoorbeeld “Add a CONTRIBUTING.md file” of “Build a simple quiz page”.
  2. Open in de rechterzijbalk Assignees, kies Copilot, voeg eventueel een extra prompt toe en klik dan op Assign.
  3. Optioneel: open het tabblad Agents en start een tweede taak in natuurlijke taal om twee agentsessies parallel te tonen.
  4. Wanneer de pull request klaar is, vraag Copilot als reviewer zodat Copilot code review-commentaar op de PR verschijnt.
  5. Wil je nog wijzigingen, reageer dan met @copilot op de pull request. Ben je tevreden, merge dan de PR — die merge is de push.

Copilot cloud agent moet op de repository ingeschakeld zijn. Bekijk de plannenpagina

En klaar: je code staat op GitHub, volledig via de browser.

⌨️

Best voor technische beginners

Ik voel me goed in een terminal ↗ bron ↗ bron ↗ bron

IT-teams, technische onderzoekers, gevorderde studenten

Copilot CLI is een sterke route van niveau 2 wanneer je van natuurlijke taal houdt maar de terminal toch dichtbij wilt houden.

Installatieopties
  • npm install -g @github/copilot
  • winget install GitHub.Copilot
  • brew install --cask copilot-cli
  • curl -fsSL https://gh.io/copilot-install | bash
  1. Installeer Copilot CLI, ga naar je projectmap en start copilot.
  2. Typ de eerste keer /login en volg de prompts om je GitHub-account te authenticeren.
  3. Bevestig dat je de bestanden in de huidige map vertrouwt voor AI-gebruik wanneer daarom gevraagd wordt.
  4. Schrijf daarna gewoon wat je wilt, bijvoorbeeld: “Create a simple HTML quiz page about photosynthesis with 5 questions, then commit and push it to a new branch and open a pull request.”
  5. Bekijk het plan of de uitvoering, behoud de nuttige wijzigingen en laat Copilot je helpen om de branch- en PR-flow af te ronden.

Interactieve modus is de standaard. Shift+Tab schakelt Plan-modus in vóór er code geschreven wordt, en copilot -p "prompt" is de niet-interactieve route.

En klaar: je code staat op GitHub, met Copilot als gids voor het terminalwerk in plaats van rauwe git-kennis uit het hoofd.

🖱️

Best voor visuele review

Ik wil een grafische interface ↗ bron

Mensen die knoppen, diffs en een zichtbare reviewstap willen

GitHub Desktop is de brugoptie: je bouwt met Copilot waar je wilt en reviewt, commit en pusht daarna visueel.

  1. Download GitHub Desktop van desktop.github.com en meld je aan met je GitHub-account.
  2. Clone je nieuwe repository of open de lokale projectmap die je elders met Copilot bewerkt.
  3. Maak je inhouds- of codewijzigingen met Copilot in de browser of in je favoriete editor.
  4. Ga terug naar GitHub Desktop, bekijk de diff, laat Copilot een commitboodschap of beschrijving voorstellen en klik dan op Commit.
  5. Klik op Push origin en open indien nodig de pull request vanuit GitHub Desktop of github.com.

Dit pad is vooral fijn als je een duidelijk “ik bekijk de diff voordat hij mijn machine verlaat”-moment wilt.

En klaar: je code staat op GitHub, zonder dat je in een terminal hoeft te wonen.
