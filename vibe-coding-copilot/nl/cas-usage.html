🎓 Docenten Copilot ChatInline-suggesties

Bouw in één sessie een zelfnakijkende quiz

Je wilt een quiz die je studenten kunnen gebruiken om een hoofdstuk te herhalen, zonder een externe betaalde tool.

  1. Open Copilot Chat en beschrijf je quiz: “Bouw een HTML-pagina met een quiz van 5 meerkeuzevragen over [onderwerp], met een eindscore.”
  2. Lees de gegenereerde code, test ze in je browser, en vraag daarna telkens één precieze aanpassing, bijvoorbeeld: “Voeg een korte uitleg toe onder elke vraag zodra ze beantwoord is.”
  3. Zodra het resultaat je bevalt, vraag je Copilot om een knop “quiz herstarten” toe te voegen.

Resultaat: Een werkende, aangepaste quiz voor je vak, klaar om te publiceren.

Ga verder: Vraag Copilot om de vraagvolgorde bij elke start te schudden.

🎓 Docenten Copilot SpacesCopilot Chat

Veranker een schemauitleg met Copilot Spaces

Je hebt slides, een gescand schema en tutor-notities en wilt een toegankelijke digitale uitleg in plaats van nog een afbeelding in een pdf.

  1. Maak een Space aan en voeg de schema-afbeelding, de relevante slidetekst en een heldere legenda toe.
  2. Vraag Copilot Chat om dat gegronde materiaal om te zetten in een HTML/CSS-pagina met labels, alt-tekst en een kleine begrippenlijst.
  3. Publiceer de goedgekeurde versie op GitHub Pages zodat studenten er buiten de les naar kunnen terugkeren.

Resultaat: Een duidelijkere, herbruikbare uitleg die in je eigen lesmateriaal verankerd is.

Ga verder: Gebruik dezelfde Space voor het volgende schema-intensieve onderwerp in plaats van alles opnieuw uit te leggen.

🎓 Docenten Copilot Chat

Genereer varianten van oefeningen om overschrijven te beperken

Je wilt meerdere versies van dezelfde oefening voor verschillende groepen studenten.

  1. Geef Copilot Chat een bestaande oefening en vraag: “Genereer 4 varianten van deze oefening met andere waarden maar dezelfde moeilijkheidsgraad.”
  2. Vraag om een gedeeld correctiemodel: “Voeg een correctiemodel toe dat elke stap uitlegt.”
  3. Vraag Copilot om alles te exporteren naar één gestructureerd document.

Resultaat: Meerdere klaar-om-te-verspreiden versies, met een consistent correctiemodel.

Ga verder: Vraag Copilot om ook een toegankelijke versie te genereren voor schermlezers.

Automatiseer een gewogen-gemiddelde calculator met de agent-modus

Je beheert een complex puntenoverzicht en wilt automatisch gewogen gemiddelden berekenen.

  1. Beschrijf je puntensysteem aan de agent-modus: “Bouw een pagina die een gewogen gemiddelde berekent op basis van deze categorieën: [lijst].”
  2. Bekijk het voorgestelde plan van de agent voordat je het goedkeurt.
  3. Vraag om een CSV-export toe te voegen om resultaten met collega's te delen.

Resultaat: Een betrouwbare calculator, afgestemd op jouw eigen puntensysteem.

Ga verder: Koppel hem aan een echte database (zie het traject Gevorderd) om hem elk semester te hergebruiken.

🧑‍🎓 Studenten Inline-suggestiesCopilot Chat

Leer coderen met Copilot als tutor, niet als kruk

Je begint met programmeren en wilt code begrijpen, niet enkel kopiëren.

  1. Schrijf eerst zelf een eenvoudige functie, ook al is ze onvolledig.
  2. Vraag Copilot Chat: “Leg regel voor regel uit wat deze code doet.”
  3. Vraag daarna: “Overhoor me over één punt om te controleren of ik het begrepen heb.”

Resultaat: Een echt begrip van de code, niet zomaar kopiëren en plakken.

Ga verder: Vraag Copilot om een iets moeilijkere oefening over hetzelfde concept.

  1. Beschrijf de flashcard-app die jullie willen aan Copilot Chat.
  2. Gebruik Copilot in de terminal om de repository aan te maken: beschrijf wat je wilt doen, Copilot stelt het exacte git-commando voor.
  3. Deel de GitHub Pages-link met de groep.

Resultaat: Een gratis, gedeeld herhalingsinstrument onder controle van de groep.

Ga verder: Voeg een eenvoudig stemsysteem toe voor de beste fiches.

🖥️ IT- en digitale diensten Agent-modusCopilot Chat

Prototype een interne tool in één uur

Een dienst vraagt om een kleine interne tool en je wilt snel een werkend prototype, voordat je engineeringtijd investeert.

  1. Beschrijf de kernbehoefte van de tool aan de agent-modus: “Bouw een pagina waar personeel een aanvraag kan indienen en de status kan zien.”
  2. Bekijk het voorgestelde plan en laat de agent een eerste versie bouwen.
  3. Vraag om een realistische verfijning, zoals formuliervalidatie of een statuskleurcode.

Resultaat: Een werkend prototype in minder dan een uur, om de behoefte te valideren vóór een volledige bouw.

Ga verder: Als het nuttig blijkt, plan dan een volwaardige versie met een echte database en toegangsbeheer.

Documenteer een bestaand script automatisch

Resultaat: Duidelijke documentatie voor een script dat voorheen maar één persoon begreep.

Ga verder: Voeg de gegenereerde README rechtstreeks toe aan de repository van het script.

Laat Copilot cloud agent een cursus-FAQ bijwerken vanuit issues

Studenten stellen elke week dezelfde vragen en je wilt de FAQ via reviewbare pull requests updaten in plaats van met handmatig kopiëren en plakken.

  1. Open een issue zoals “Voeg de terugkerende vragen van deze week toe aan de FAQ” en koppel de cursus-Space als je die al gebruikt.

Resultaat: Een cursus-FAQ die week na week beter wordt zonder dat het docententeam webbeheerders moet worden.

Ga verder: Herhaal hetzelfde issuepatroon na elk lesblok zodat de FAQ een levend lesinstrument wordt.

  2. Vraag daarna aan Agent-modus of Copilot CLI om die skill op het ticket van vandaag toe te passen in plaats van van een lege shell te vertrekken.
  3. Bekijk het script of de diff eerst na vóór je iets uitvoert in de doelomgeving.

Resultaat: Herhaalbare interne automatiseringen met minder copy-paste-afwijking tussen technici.

Ga verder: Versioneer de skill op GitHub zodat één update het vertrekpunt van het hele team verbetert.
