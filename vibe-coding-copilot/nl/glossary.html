Home/Glossarium

Glossarium

Korte definities van termen die overal op de site terugkomen, met een bronlink wanneer die bestaat.

Copilot-features, context en agents

Copilot Chat

↗ bron

Gespreksinterface om Copilot te vragen iets uit te leggen, te herschrijven of mee op te bouwen.

Agent mode

↗ bron

Modus waarin Copilot meerdere stappen kan plannen en uitvoeren in plaats van alleen tekst terug te geven.

Copilot cloud agent

↗ bron

Een door GitHub gehoste agent die toegewezen taken kan opnemen vanuit issues of natuurlijke taal.

Copilot CLI

↗ bron

De command-line-interface om Copilot vanuit een terminal te gebruiken, interactief of in scripts.

GitHub Copilot app

↗ bron

De GitHub-appomgeving die agentische taken en GitHub-native workflows samenbrengt.

Copilot Spaces

↗ bron

Contextspaces waarin je bestanden, referenties en instructies bundelt voor beter gegronde antwoorden.

Copilot Memory

↗ bron

Mogelijkheid waarbij Copilot bepaalde voorkeuren, feiten of beslissingen kan hergebruiken in de juiste context.

MCP-servers

↗ bron

Model Context Protocol-servers die tools of betrouwbare data aanbieden zodat Copilot met echte systemen kan werken.

Prompt files

↗ bron

Herbruikbare instructiebestanden om prompts en verwachte output consistenter te maken.

Custom agents

↗ bron

Agents die op maat gemaakt zijn voor een rol of workflow, met gerichte instructies en soms extra tooling.

Agent skills

↗ bron

Herbruikbare vaardigheden die een agent kan oproepen voor afgebakende of terugkerende taken.

AI credits

↗ bron

Verbruikseenheden voor sommige geavanceerde modellen of agentische workloads, afhankelijk van het Copilot-plan.

GitHub-basis om te starten

Repository

↗ bron

De GitHub-projectruimte waar bestanden, geschiedenis en instellingen samenkomen.

Commit

↗ bron

Een vastgelegde wijziging in de projectgeschiedenis.

Branch

↗ bron

Een parallelle werkstroom om wijzigingen te testen voordat je ze in de hoofdbranch samenbrengt.

Pull Request

↗ bron

Een verzoek om wijzigingen uit één branch te laten nalezen en samen te voegen in een andere.

Issue

↗ bron

Een GitHub-ticket voor ideeën, bugs, taken of werkverzoeken.

GitHub Pages

↗ bron

De statische hostingdienst van GitHub om snel een site of prototype vanuit een repository te publiceren.

Onderwijs en uitrol

GitHub Campus Program

↗ bron

Een programma voor in aanmerking komende instellingen die GitHub-platformcapaciteit op instellingsniveau willen.
