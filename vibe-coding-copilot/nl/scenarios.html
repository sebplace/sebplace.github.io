Acht echte scenario’s per rol

Gebruik ze als demo, workshopscript of intern adoptieverhaal. Elk scenario hieronder is verankerd in een echte GitHub Copilot-feature uit de officiële documentatie.

Als je nog twijfelt tussen nood aan voorbeelden, uitrolvragen of eerst een echte GitHub-lus, doe de diagnose in 2 minuten om de juiste volgende pagina te kiezen.

Feiten gecontroleerd Feiten gecontroleerd in augustus 2026 op docs.github.com — GitHub Copilot evolueert snel, dus controleer exacte cijfers opnieuw vóór een aankoopbeslissing.

Eerst de opstart nodig?

Gebruik de eerste-commitgids als je publiek nog de glasheldere route nodig heeft van GitHub-sign-up tot een echte gemergede pull request met Copilot.

🎓 Docent
Copilot ChatGitHub PagesCopilot Spaces

Live iets zichtbaars bouwen zonder zware installatie.

Een docent heeft een cursusoverzicht, wil een herhalingsquiz en één oefenpagina, maar wil niet eerst een volledige toolchain optuigen om het idee te testen.

Wat er gebeurt

  1. Open github.com/copilot in de browser en plak het cursusoverzicht.
  2. Vraag Copilot Chat om een eerste statische versie die je meteen via GitHub Pages kunt publiceren.
  3. Maak daarna een Copilot Space “Mijn syllabus” met slides, readings en begrippenlijst zodat toekomstige antwoorden in dit vak gegrond blijven.
Copilot
Ik geef eerstejaars microbiologie. Bouw een GitHub Pages-vriendelijke minisite met één index.html, één style.css en één script.js. Ik wil 6 meerkeuzevragen, één casusoefening, directe feedback en een resetknop. Hou de taal studentvriendelijk.
Hier is een eerste versie met de drie bestanden, een nette lay-out en de eerste zes vragen klaar om op jouw cursus af te stemmen. Ik heb ook commentaar toegevoegd zodat je snel kunt aanpassen vóór publicatie.

Concreet resultaat

  • Een werkende herhalingspagina in een repository
  • Een GitHub Pages-URL die je dezelfde dag kunt delen
  • Een herbruikbare Space voor de volgende opdracht of FAQ

Waarom dit aanslaat

Het wow-effect is direct: je praat niet over AI, je toont een echt onderwijsartefact dat al bestaat.

🧑‍🎓 Student
Copilot StudentAgent-modusCopilot code review

Van eindprojectidee naar werkende app, branch per branch.

Een studententeam heeft een projectbrief, weinig tijd en wil van idee naar MVP gaan terwijl het de code nog altijd begrijpt.

Wat er gebeurt

  1. Gebruik het gratis Copilot Student-voordeel in VS Code.
  2. Laat Agent-modus het MVP branch per branch opzetten in plaats van één enorme sprong te maken.
  3. Laat Copilot code review vóór de indiening op de pull requests draaien zodat het team gerichte verbeterpunten krijgt.
Copilot
Agent-modus: bouw een minimum viable app voor reservatie van labomateriaal voor een eindproject. Start met een landingspagina, aanvraagformulier, adminlijst, README en voeg daarna één feature per branch toe. Leg elke grote wijziging uit vóór je ze toepast.
Ik kan beginnen met het repo-plan, de eerste branch opzetten en daarna reviewbare wijzigingen openen voor formulier en adminweergave afzonderlijk zodat het project begrijpelijk blijft.

Concreet resultaat

  • Een werkend MVP in plaats van enkel een conceptnota
  • Een duidelijkere branch- en commitgeschiedenis voor begeleiders
  • Reviewcommentaar dat de codekwaliteit vóór de indiening versterkt

Waarom dit aanslaat

De ervaring blijft hands-on: Copilot versnelt, maar de branchstructuur en reviewcyclus houden het leren zichtbaar.

🖥️ IT & digitale diensten
GitHub Copilot-appParallelle agentsPlan-modus

Meerdere interne tickets parallel aanpakken zonder controle te verliezen.

Een IT-team heeft een stapel kleine tickets — een pagina restylen, een script migreren, een formulier verbeteren — en wil snelheid zonder chaos.

Wat er gebeurt

  1. Start de GitHub Copilot-app en open meerdere agentsessies parallel.
  2. Blijf in Plan-modus zodat het team plannen en diffs bekijkt vóór uitvoering.
  3. Gebruik de native GitHub-integratie om elke goedgekeurde wijziging in de normale branch / PR / CI-flow te brengen.
Copilot
Maak drie Plan-modussessies: 1) migreer dit CSV-opruimscript naar Python, 2) vernieuw de startpagina van de personeelsgids, 3) voeg gestructureerde logging toe aan de ruimteboekingsservice. Houd elke taak in zijn eigen worktree en toon het plan vóór er iets wordt aangepast.
Ik heb drie aparte plannen klaargezet, elk in zijn eigen sessie en branch. Het team hoeft alleen de diffs te bekijken en goed te keuren wat deze week echt moet landen.

Concreet resultaat

  • Drie parallelle werkstromen in plaats van één geblokkeerde rij
  • Reviewbare diffs per ticket
  • Een sneller backlogsritme met menselijke goedkeuring in de lus

Waarom dit aanslaat

Hier voelt agent-driven development operationeel nuttig: parallel, geïsoleerd en reviewbaar.

🤝 HR
Copilot SpacesCopilot Chat

Een interne assistent bouwen die in beleid verankerd is, zonder zelf een backend te schrijven.

HR beantwoordt voortdurend dezelfde vragen over onboarding, verlof of contractsjablonen en wil antwoorden die aansluiten op de echte documenten.

Wat er gebeurt

  1. Maak één Space met het canonieke HR-materiaal.
  2. Gebruik Copilot Chat op die Space om antwoorden en een eenvoudige FAQ-pagina op te stellen.
  3. Lees na, pas de toon aan en publiceer de goedgekeurde versie als intern referentiepunt.
Copilot
Maak een Space “HR-beleid” met onboardinggidsen, verlofprocedures, contractsjablonen en FAQ-notities. Stel daarna een personeelsgerichte vragenpagina op die de 12 meest voorkomende vragen beantwoordt en per antwoord duidelijk naar de bron verwijst.
Ik heb het bronmateriaal gegroepeerd, antwoordpatronen opgesteld die op die documenten steunen, en een heldere FAQ-pagina gemaakt die HR kan nalezen vóór interne publicatie.

Concreet resultaat

  • Een FAQ die in documenten verankerd is in plaats van nog een overlopende mailbox
  • Snellere antwoorden voor personeel
  • Een herbruikbare Space die toekomstige HR-prompts verbetert

Waarom dit aanslaat

De echte winst is vertrouwen: mensen krijgen antwoorden uit de documenten van de instelling zelf, niet uit generieke webtaal.

🧭 Directie
Custom agentsCopilot cloud agentAutomations

Wekelijkse KPI-jacht omzetten in een geplande, reviewbare synthese.

Een directie of diensthoofd wil één beknopt wekelijks beeld over meerdere teams zonder alles handmatig samen te voegen.

Wat er gebeurt

  1. Maak een aangepaste agentpersona die bij de gewenste rapportagestijl past.
  2. Plan een wekelijkse run van de Copilot cloud agent.
  3. Bekijk een PR in plaats van een ondoorzichtige bijlage vóór de samenvatting wordt verspreid.
Copilot
Definieer in .github/agents/reporting.md een agent die KPI-bestanden uit /finance, /student-success, /research en /operations leest en vervolgens een weekly-summary.md met successen, risico’s en open vragen schrijft. Plan de run elke vrijdagmiddag en open een pull request in plaats van main rechtstreeks te wijzigen.
Ik kan die aangepaste agentinstructies volgen, de bronbestanden samenbrengen en een reviewbare PR openen met de voorgestelde samenvatting zodat de directie het narratief goedkeurt vóór het gedeeld wordt.

Concreet resultaat

  • Een reproduceerbaar wekelijks rapportageritueel
  • Eén PR waar directie commentaar op kan geven
  • Minder coördinatietijd verloren aan het kopiëren van statusupdates

Waarom dit aanslaat

De directie krijgt de snelheid van automatisering en behoudt tegelijk het institutionele reviewmoment vóór publicatie.

💶 Financiën
Prompt filesCopilot ChatAI credits

Een maandelijks exportbestand in minuten omzetten in een dashboard mét begrijpelijk kostenverhaal.

Het financeteam ontvangt bij elke cyclus dezelfde Excel- of CSV-export en wil een licht dashboard in plaats van telkens dezelfde spreadsheetweergave opnieuw op te bouwen.

Wat er gebeurt

  1. Maak één gedeeld prompt file voor deze terugkerende financiële workflow.
  2. Voer maandelijks gewoon het actuele exportbestand in in plaats van de taak opnieuw uit te leggen.
  3. Volg die run binnen de gedeelde AI-creditpool van de organisatie in plaats van te gissen naar een vlak mysteriebedrag.
Copilot
Gebruik .github/prompts/rapport-budget.prompt.md met de invoer [exportbestand] en [maand]. Zet het bijgevoegde budgetexport om in een statisch dashboard met variatiekaarten, een sorteerbare tabel en overschrijdingswaarschuwingen. Houd alle berekeningen zichtbaar in code en schat het AI-creditgebruik van deze run.
Ik heb het prompt-file-sjabloon voorbereid, de export omgezet in een dashboard van één pagina en de formules zichtbaar gehouden zodat het team zowel de cijfers als het proces kan auditen.

Concreet resultaat

  • Een herbruikbare dashboardworkflow
  • Zichtbare berekeningen in code
  • Een concreet financieel verhaal waarom gedeelde AI credits beter bestuurbaar zijn dan giswerk

Waarom dit aanslaat

Financiën hoeven geen hype te kopen: het resultaat spreekt in snellere rapportering en transparanter kostbeheer.

🔬 Onderzoek
MCP serversCopilot ChatPython / R-scriptgeneratie

Een dataset natuurlijke taalvragen laten beantwoorden en toch het script achter het antwoord krijgen.

Onderzoekers willen sneller bij vertrouwde data, maar hebben ook reproduceerbaarheid en een controleerbaar analysepad nodig.

Wat er gebeurt

  1. Verbind een goedgekeurde MCP-server met de relevante dataset.
  2. Stel de vraag in Copilot Chat in plaats van eerst handmatig de eerste query bijeen te puzzelen.
  3. Neem het gegenereerde Python- of R-script als reproduceerbaar artefact voor review, hergebruik of communicatie.
Copilot
Gebruik de goedgekeurde retention-data-MCP-server om retentie voor cohorten 2022 tot 2025 per faculteit te vergelijken. Genereer daarna het Python-notebook dat de grafiek reproduceert en voorzie commentaar bij elke transformatiestap.
Ik kan de gekoppelde bron bevragen, de vergelijking in gewone taal samenvatten en het notebook genereren zodat het team de methode kan herhalen of aanpassen.

Concreet resultaat

  • Een sneller pad van vraag naar eerste analyse
  • Een script dat het team kan inspecteren en opnieuw kan uitvoeren
  • Een gegronde workflow die onderzoekstraceerbaarheid respecteert

Waarom dit aanslaat

Je behoudt het gemak van natuurlijke taal zonder de reproduceerbaarheid op te offeren die onderzoek nodig heeft.

📚 Bibliotheek / campusdiensten
Agent-modusGitHub PagesGitHub Campus Program

Een niet-ontwikkelteam laten landen met een nuttige mini-app dit semester.

Bibliotheek- of campusmedewerkers hebben een eenvoudige ruimteboekings- of inventaristool nodig en willen snel iets bruikbaars.

Wat er gebeurt

  1. Gebruik Agent-modus om de eerste versie snel op te zetten.
  2. Host de app op GitHub Pages binnen de GitHub-platformvoetafdruk van de instelling.
  3. Houd de inhoud zo bewerkbaar dat bibliotheek- of campusmedewerkers na de lancering eigenaar kunnen blijven.
Copilot
Bouw een statisch prototype voor ruimteboekingen in de bibliotheek: datumkiezer, ruimtekaarten, bezet/vrij-status met fictieve data, toegankelijkheidsnotities en een GitHub Pages-deployworkflow. Houd de structuur eenvoudig genoeg zodat niet-ontwikkelaars later zelf kunnen onderhouden.
Ik heb een kleine statische app opgezet, toegankelijke ruimtekaarten toegevoegd en een deployworkflow voorzien, terwijl de contentbestanden eenvoudig genoeg blijven voor het serviceteam na de lancering.

Concreet resultaat

  • Een werkend serviceprototype in plaats van een lange wachtlijst
  • Gratis statische hosting via GitHub Pages
  • Een tastbaar voorbeeld van wat het Campus Program-platform mogelijk maakt

Waarom dit aanslaat

Het team ziet meteen de waarde omdat het resultaat een bruikbare servicepagina is, geen abstracte AI-pilot.
