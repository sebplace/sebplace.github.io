Inline suggestions

Autocomplete-style code suggestions in your IDE, plus next edit suggestions in supported editors.

Copilot Chat

Ask, refine, explain, and build in plain language on github.com/copilot, mobile, IDEs, or Windows Terminal.

Agent mode

Copilot works more autonomously in your IDE, planning and applying multi-file changes with approval checkpoints.

Copilot CLI

Describe terminal work in natural language and keep the flow moving in the command line.

Copilot code review

AI review suggestions and reviewer focus areas before or during human review.

Copilot cloud agent

Assign a task or issue, let Copilot work on a branch, then review the pull request.

Copilot Spaces

Ground Copilot with repos, files, free text, transcripts, and images in a shareable space.

MCP servers

Connect Copilot to trusted external tools and data sources.

GitHub Copilot app

Run separate Copilot agent sessions in their own worktrees, compare diffs, and keep several tasks moving in parallel.

Custom instructions

Repository or path-specific guidance that keeps naming, tone, accessibility, and build rules consistent.

Prompt files

Reusable task templates stored in the repository so recurring work starts from a shared prompt instead of a blank chat.

Custom agents

Repository-defined agents with a specific job, style, or workflow.

Agent skills

Reusable skill bundles that teach agents how your team wants repetitive tasks done.

Copilot Memory

Remember useful project context so recurring work does not restart from zero every session.

🎓 Teaching staff Copilot ChatInline suggestions

Build a self-marking quiz in one sitting

You want a quiz your students can use to revise a chapter, without an external paid tool.

  1. Open Copilot Chat and describe your quiz: “Build an HTML page with a 5-question multiple-choice quiz about [topic], showing a final score.”
  2. Read the generated code, test it in your browser, then ask one precise change at a time, e.g. “Add a short explanation under each question once it's answered.”
  3. Once you're happy with it, ask Copilot to add a “restart quiz” button.

Result: A working, customized quiz for your course, ready to publish.

Go further: Ask Copilot to shuffle the question order on every launch.

🎓 Teaching staff Copilot SpacesCopilot Chat

Ground a diagram explainer with Copilot Spaces

You have slides, a scanned diagram, and tutor notes, and you want an accessible digital explainer instead of one more image embedded in a PDF.

  1. Create a Space and upload the diagram image, the relevant slide text, and a plain-language caption.
  2. Ask Copilot Chat to turn that grounded material into an HTML/CSS explainer with labels, alt text, and a short glossary.
  3. Publish the approved version on GitHub Pages so students can revisit it outside class.

Result: A clearer, reusable explainer grounded in your own teaching material.

Go further: Reuse the same Space for the next diagram-heavy topic instead of restating the context from scratch.

🎓 Teaching staff Copilot Chat

Generate exercise variants to reduce copying

You want several versions of the same exercise for different student groups.

  1. Give Copilot Chat an existing exercise and ask: “Generate 4 variants of this exercise with different values but the same difficulty.”
  2. Ask for a shared marking scheme: “Add a marking scheme explaining each step.”
  3. Ask Copilot to export everything into one structured document.

Result: Several ready-to-distribute versions with a consistent marking scheme.

Go further: Ask Copilot to also generate an accessible version for screen readers.

🎓 Teaching staff Agent modeCopilot Chat

Automate a weighted grade calculator with agent mode

You manage a complex grading spreadsheet and want automatic weighted averages.

  1. Describe your grading scheme to agent mode: “Build a page that calculates a weighted average from these categories: [list].”
  2. Review the plan the agent proposes before approving it.
  3. Ask it to add a CSV export to share results with colleagues.

Result: A reliable calculator matched to your own grading scheme.

Go further: Connect it to a real database (see the Advanced track) to reuse it every semester.

🧑‍🎓 Students Inline suggestionsCopilot Chat

Learn to code with Copilot as a tutor, not a crutch

You're new to programming and want to understand code, not just copy it.

  1. Write a simple function yourself first, even an incomplete one.
  2. Ask Copilot Chat: “Explain line by line what this code does.”
  3. Then ask: “Quiz me on one thing to check I understood.”

Result: Real understanding of the code, not just copy-pasting.

Go further: Ask Copilot for a slightly harder exercise on the same concept.

🧑‍🎓 Students Copilot ChatCopilot CLI

Build a shared revision site for your study group

Your study group wants one shared place to revise before the exam.

  1. Describe the flashcard app you want to Copilot Chat.
  2. Use Copilot in the terminal to create the repository: describe what you want to do, Copilot suggests the exact git command.
  3. Share the GitHub Pages link with the group.

Result: A free, shared revision tool your whole group controls.

Go further: Add a simple upvote system for the best flashcards.

🧑‍🎓 Students Copilot Chat

Present your thesis or internship report online

You need to structure a long document and automate repetitive parts like a table of contents.

  1. Ask Copilot to generate a site skeleton to present your thesis online (summary, chapters, appendices).
  2. Ask for an interactive table of contents built from your section headings.
  3. Add a contact page to receive feedback.

Result: An online, presentable version of your thesis, alongside the classic document.

Go further: Ask Copilot to add keyword search across the content.

🧑‍🎓 Students Copilot SpacesCopilot Chat

Build a portfolio grounded in your real project files

You want a portfolio site without rewriting every project description from scratch.

  1. Create a Space with your README files, project screenshots, internship summary, and key links.
  2. Ask Copilot Chat to draft a one-page portfolio with project cards and short outcome-focused bullets.
  3. Refine the tone, then publish the result on GitHub Pages.

Result: A portfolio that is faster to build because the raw material is already grounded.

Go further: Keep the Space updated each semester so future portfolio refreshes become a short editing pass.

🖥️ IT & digital services Agent modeCopilot Chat

Prototype an internal tool in one hour

A department asks for a small internal tool and you want a working prototype fast, before committing engineering time.

  1. Describe the tool's core need to agent mode: “Build a page where staff can submit a request and see its status.”
  2. Review the proposed plan and let the agent build a first version.
  3. Ask for one realistic refinement, like form validation or a status colour code.

Result: A working prototype in under an hour, to validate the need before a full build.

Go further: If it proves useful, plan a proper version with a real database and access control.

🖥️ IT & digital services Copilot Chat

Document an existing script automatically

You've inherited an undocumented internal script and need to understand and document it fast.

  1. Open the script and ask Copilot Chat: “Explain what this script does, step by step.”
  2. Ask: “Generate a README describing its purpose, inputs, and how to run it.”
  3. Ask Copilot to flag any risky or unclear parts of the code.

Result: Clear documentation for a script that previously only one person understood.

Go further: Add the generated README directly to the script's repository.

🖥️ IT & digital services Copilot ChatAgent mode

Automate a deployment with GitHub Actions

You want a small site or tool to redeploy automatically whenever it changes.

  1. Ask Copilot Chat: “Generate a GitHub Actions workflow that deploys this site to GitHub Pages on every push to main.”
  2. Add the suggested file to your repository and push a small change to test it.
  3. Ask Copilot to add a notification step if the deployment fails.

Result: A site that updates itself automatically, with no manual redeploy step.

Go further: Reuse the same workflow file as a template for other internal projects.

  2. Ask it to store submissions so you can review them afterwards.
  3. Ask for a simple summary view showing the average rating.

Result: A working feedback form, live before the session even ends.

Go further: Reuse the same page as a template for every future training session.

🎓 Teaching staff Prompt filesCustom instructionsCopilot Chat

Turn one lab brief into three safe exercise variants

You have one practical brief and you want several variants that keep the same learning goals, rubric language, and safety wording.

  1. Create a prompt file in the repository that asks for a variant, an answer key, and a short teacher note.
  2. Add custom instructions for tone, accessibility, and any lab-safety wording that must stay untouched.
  3. Ask Copilot Chat for three versions, then keep the approved set in the same course repository.

Result: A reusable variation workflow instead of rewriting the same exercise every semester.

🎓 Teaching staff Copilot cloud agentCopilot code reviewCopilot Spaces

Let Copilot cloud agent refresh a course FAQ from issues

Students keep asking the same weekly questions and you want the FAQ page updated through reviewable pull requests rather than manual copy-paste.

  1. Open an issue such as “Add this week’s recurring questions to the FAQ” and attach the grounded course Space if you already use one.
  2. Assign the issue to Copilot so the cloud agent drafts the page update on its own branch.
  3. Request Copilot code review on the pull request, review the wording yourself, then merge the approved update.

Result: A course FAQ that improves week by week without turning the teaching team into web maintainers.

Go further: Use the same issue pattern after every lecture block so the FAQ becomes a living teaching asset.

🧑‍🎓 Students Copilot MemoryCopilot Chat

Keep an internship or thesis project moving with Copilot Memory

You return to the same project every week and do not want to restate the context, stack, deadlines, and constraints from scratch every single time.

  1. Store the stable project context in a Memory-enabled Copilot workflow and mirror the most important decisions in the repository README.
  2. Ask Copilot Chat for the next milestone, a progress summary, or a cleanup pass on the current code.
  3. Commit each approved change so the project history stays visible to supervisors and teammates.

Result: A steadier project rhythm with less time lost re-explaining the same background.

Go further: Memory helps with continuity, but the real source of truth should still live in the repository.

🖥️ IT & digital services Agent skillsAgent modeCopilot CLI

Standardise helpdesk cleanup scripts with Agent skills

Different technicians solve the same account-cleanup or log-collection ticket in slightly different ways, and the variation creates avoidable risk.

  1. Define an Agent skill with the approved script pattern, logging format, and rollback expectations.
  2. Ask Agent mode or Copilot CLI to adapt that skill to the current ticket instead of starting from a blank shell.
  3. Review the resulting script or diff before running it in the target environment.

Result: Repeatable internal automations with less copy-paste drift between technicians.

Go further: Version the skill in GitHub so one update improves the whole team’s starting point.

🤝 HR Custom instructionsCopilot code reviewCopilot Chat

Keep policy pages consistent with custom instructions

HR updates policies often, but headings, tone, required caveats, and inclusive wording drift from page to page.

  1. Put the required tone, section order, inclusive wording, and approval notes in .github/copilot-instructions.md.
  2. Ask Copilot Chat to draft the updated page using those repository rules.
  3. Open a pull request and use Copilot code review as a second pair of eyes before publishing internally.

Result: Faster policy-page drafting with fewer formatting corrections later in the process.

Go further: Extend the instructions file each time HR or Legal adds a new must-have section.

🧭 Leadership & management Custom agentsGitHub Copilot appCopilot code review

Create a custom agent that turns pilot ideas into comparable briefs

Several departments pitch small internal tools at once, and leadership needs a comparable brief for each proposal before deciding what to fund.

  1. Define a custom agent that must always output the same sections: problem, users, low-risk first version, data sensitivity, and next step.
  2. Run that agent in separate GitHub Copilot app sessions, one proposal per worktree.
  3. Compare the resulting briefs and PR summaries side by side instead of comparing informal hallway requests.

Result: A reviewable pipeline of lightweight prototypes instead of a backlog of vague requests.

Go further: Keep the winning briefs in a shared gallery repository so the next team can fork an existing idea instead of starting from zero.

💶 Finance & administration Prompt filesCustom instructionsCopilot Chat

Generate monthly budget notes in one shared house style

Finance turns the same export into monthly comments, but wording and tables vary from person to person.

  1. Store formatting rules and mandatory headings in custom instructions.
  2. Create a prompt file that asks for a variance summary, top exceptions, and next actions from the pasted export.
  3. Run the prompt each month, then review the draft note in a pull request before it circulates.

Result: More consistent monthly reporting with visible rules in the repository.

Go further: This is especially useful when several people rotate across the same reporting workflow.

🔬 Researchers MCP serversAgent modeCopilot Chat

Ask a lab scheduling system for utilisation patterns through MCP

A research platform team wants to understand which equipment slots stay underused without manually exporting and reshaping the same files every month.

  1. Connect Copilot to the approved scheduling system through an MCP server or another governed connector.
  2. Ask for utilisation by day, room, or lab in plain language to identify obvious underuse patterns.
  3. Let Agent mode generate the dashboard or notebook that reproduces the answer so the method stays inspectable.

Result: A faster path from operational question to reproducible utilisation view.

Go further: Keep the connection scoped to approved data only and reuse the same prompts each semester.

  2. Ask Copilot Chat to draft a searchable help page or chatbot copy grounded in that material.

📚 Library, comms & campus life Agent modeCopilot code reviewCopilot Chat

Ship a small incident-reporting form for campus facilities

Facilities staff need a lightweight way to collect location, photo, urgency, and follow-up status for minor incidents without waiting for a full platform replacement.

  1. Ask Agent mode to scaffold the form, confirmation screen, and the simplest useful storage pattern for a pilot.
  2. Use Copilot code review to check field labels, validation, and the clarity of the follow-up flow.

Go further: If the pilot works, move it into a shared repo with a code owner instead of leaving it on one laptop.
