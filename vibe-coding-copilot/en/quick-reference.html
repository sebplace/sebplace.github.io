2-minute guide

The short, opinionated page for understanding what this site offers and choosing the next useful click.

Vibe Coding Copilot is a trilingual static site for people who teach, study, support, or lead in higher education and want to use GitHub Copilot without unnecessary jargon. If you just landed here, this page shows what the site already contains and where your time is best spent first.

Pick your situation

One need, one best next click.

I want to try Copilot right now

No install and no local repository yet: test a real prompt in the browser first.

Open github.com/copilot →🧭

I am not sure where we should start

The maturity diagnostic points you to the most useful next page for your current context.

Take the diagnostic →🪜

I want to learn step by step

The Basics track starts with the first prompt and ends with publishing a first working app.

Open the Beginner track →🎭
