Leçon 1

Travailler avec l'agent de Copilot

Au-delà des suggestions ligne par ligne, Copilot propose un mode agent : tu décris une tâche plus large (« ajoute un formulaire d'inscription à mon quiz et vérifie qu'il fonctionne »), et Copilot planifie plusieurs modifications, les applique et vérifie le résultat, avec des points d'étape que tu valides.

C'est l'outil idéal quand ton application grandit et que tu ne veux plus décrire chaque petite ligne une par une.

TipRelis toujours le plan proposé avant de laisser l'agent travailler : c'est le meilleur moment pour corriger le tir.
À toi de jouerDécris une tâche en plusieurs étapes au mode agent de Copilot (par exemple, ajouter une page de résultats à ton Sondage Éclair) et relis attentivement son plan avant de le laisser l'exécuter.

Leçon 2

Connecter une base de données à ton application

Dès que ton outil doit retenir des informations d'une session à l'autre (des réponses de quiz, des inscriptions, des notes), tu as besoin d'une base de données. Des services comme Supabase permettent d'en créer une gratuitement, sans configuration serveur, et Copilot t'aide à écrire le code de connexion.

Décris à Copilot ce que tu veux stocker (par exemple : le nom de l'étudiant et son score), et laisse-le proposer la structure de la base et le code nécessaire pour lire et écrire dedans.

À toi de jouerCrée un projet Supabase gratuit et connecte-le à une petite page de test qui stocke une seule information, comme un nom et un vote.

Leçon 3

Utiliser cette base de données en toute sécurité

Une base de données mal protégée peut exposer les données de tes étudiants. Demande systématiquement à Copilot d'ajouter des règles de sécurité (qui a le droit de lire ou d'écrire quoi), et ne stocke jamais plus d'informations personnelles que nécessaire.

Pense dès maintenant à la protection des données de tes étudiants (RGPD en Europe) : anonymise ce qui peut l'être, et explique clairement à quoi servent les données que tu collectes.

TipEn cas de doute, demande à Copilot : « ce code respecte-t-il de bonnes pratiques de protection des données ? »
À toi de jouerDemande à Copilot de relire ton code de base de données pour détecter des problèmes de sécurité, et corrige au moins un point signalé.

Leçon 4

Concevoir consciemment pour l'apprentissage

Un bon outil pédagogique n'est pas seulement fonctionnel, il est pensé pour l'apprentissage : retour immédiat après une réponse, progression visible, encouragements plutôt que sanctions. Décris ces intentions pédagogiques à Copilot, pas seulement des fonctionnalités techniques.

Par exemple, plutôt que « affiche le score », demande « affiche le score avec une explication de chaque erreur, pour que l'étudiant comprenne pourquoi il s'est trompé ».

À toi de jouerReformule une demande de fonctionnalité pour ton projet comme un prompt centré sur l'apprentissage ou l'utilisateur, en suivant l'exemple de cette leçon, plutot qu'une demande purement technique.

Leçon 5

Faire un bon plan de construction

Avant de demander une grosse fonctionnalité à Copilot, écris toi-même un petit plan en quelques lignes : les étapes, l'ordre logique, ce qui est essentiel et ce qui peut attendre. Un bon plan produit de bien meilleures suggestions qu'une demande vague.

Partage ensuite ce plan avec Copilot Chat avant de commencer à coder : il pourra te signaler des étapes manquantes ou un ordre plus logique.

À toi de jouerÉcris un plan de construction en cinq lignes pour ta prochaine fonctionnalité avant de demander le moindre code à Copilot, puis partage-le d'abord avec Copilot Chat.

Leçon 6

Itérer intelligemment sans casser ton application

Plus ton projet grandit, plus il est tentant de demander plusieurs changements à la fois. Résiste à cette tentation : une modification, un test, un commit sur GitHub. Si quelque chose casse, tu sais exactement quoi annuler.

GitHub permet de revenir en arrière très simplement grâce à l'historique des commits : c'est ton filet de sécurité pour oser itérer sans stress.

À toi de jouerFais trois petits commits séparés aujourd'hui, chacun avec un changement clair et un message de commit clair.

Leçon 7

Donner une mémoire durable à ton projet

Sans instructions spécifiques, Copilot ne gardera pas automatiquement en mémoire toutes les conventions du projet. Place un fichier .github/copilot-instructions.md dans le dépôt et note les règles répétées à chaque session : nommage, ton, étapes de build, contraintes d’accessibilité ou identité visuelle.

Tu pourras ensuite compléter avec des prompt files, des fichiers d’instructions plus ciblés, AGENTS.md ou des agents spécialisés. Commence par ce fichier toujours actif pour sortir du mode “générique”.

TipRelis et complète ce fichier au fil du projet : c'est un investissement de cinq minutes qui améliore toutes tes prochaines sessions.
À toi de jouerCrée ton premier fichier .github/copilot-instructions.md avec au moins trois règles importantes dans ton contexte : style, étapes de build et une contrainte institutionnelle.

Leçon 8

Utiliser l'IA comme testeuse

Avant de montrer ton application à de vrais étudiants, demande à Copilot Chat de jouer le rôle d'un utilisateur maladroit ou distrait : « essaie de faire planter ce formulaire », « que se passe-t-il si je laisse ce champ vide ? ».

Demande-lui aussi de générer des cas de test : des exemples de réponses correctes, incorrectes, ou complètement inattendues à ton quiz ou ton formulaire.

À toi de jouerDemande à Copilot Chat d'essayer de casser ton application de trois manières différentes, puis corrige ce qu'il trouve.

Leçon 9

Gérer ton code comme un vrai projet avec GitHub

Un projet qui dure a besoin d’une vraie organisation : commits clairs, petites branches, pull requests et relecture. Si l’établissement veut la plateforme GitHub à grande échelle, le GitHub Campus Program peut fournir GitHub Enterprise Cloud ou Server à toute l’école — mais il s’agit de la couche plateforme, pas d’une licence Copilot gratuite généralisée pour tout le personnel.

Pour Copilot lui-même, les étudiantes et les étudiants peuvent encore utiliser Copilot Student individuellement et les enseignantes et les enseignants vérifiés peuvent encore utiliser Copilot Pro gratuit individuellement. Pour l’IT, les RH, les finances, la direction et les autres fonctions, le déploiement large passe par Copilot Business ou Copilot Enterprise avec la bonne gouvernance et le bon modèle budgétaire.

À toi de jouerCrée une branche, fais-y un petit changement, et ouvre ta première pull request pour le fusionner dans ta version principale.
