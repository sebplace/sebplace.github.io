Leçon 1

Qu'est-ce que le vibe coding ?

Le vibe coding, c'est créer une application en décrivant ce que tu veux à une IA plutôt qu'en écrivant chaque ligne de code toi-même. Avec GitHub Copilot, tu expliques ton besoin en langage naturel et l'IA propose le code ; toi, tu restes aux commandes : tu lis, tu ajustes, tu valides.

Pour l'enseignement supérieur, cela change tout : tu peux enfin construire le petit outil que tu imagines depuis des années, sans attendre un service informatique ou apprendre à programmer pendant six mois. Ce parcours t'accompagne pas à pas, avec un vrai projet de cours comme fil rouge.

TipTu n'as pas besoin d'installer quoi que ce soit pour lire ce parcours. L'installation de Copilot arrive à la leçon suivante.
À toi de jouerQuel que soit ton métier (enseignement, études, IT, RH, direction, finances), écris en une phrase la petite appli que tu rêves d'avoir. Tu en construiras une vraie dès la leçon 3.

Leçon 2

D’un vrai problème de campus à une idée d’application

Le meilleur point de départ n’est jamais une technologie, mais un vrai problème de campus : des étudiantes et des étudiants n’ont pas de moyen simple de réviser, un service répond sans cesse à la même question par e-mail, une équipe suit une ligne budgétaire dans dix tableurs, un laboratoire veut une page de réservation légère. Pars du frottement réel.

Décris ce problème en une phrase, puis imagine la plus petite application possible pour réduire ce frottement. Un quiz, une page, un calculateur, un suivi, une FAQ consultable : garde la première version simple, puis élargis quand de vraies personnes l’utilisent.

TipÉcris ton idée sous la forme : « Une application qui permet à [qui] de [faire quoi] pour [quel bénéfice] ».
À toi de jouerChoisis UN vrai problème dont tu ou une ou un collègue se plaint chaque semaine, en classe, au support IT, en onboarding ou en réunion budget, et écris ton idée avec la formule ci-dessus.

Leçon 3

Ta première web app avec GitHub Copilot

C’est la leçon où tu construis vraiment quelque chose. Installe l’extension GitHub Copilot dans Visual Studio Code, ou ouvre Copilot Chat directement sur github.com/copilot avec ton compte GitHub, puis crée un nouveau fichier index.html.

Ci-dessous, on construit ensemble un exemple réel et fonctionnel : un « Sondage Éclair » que tu peux utiliser en cours, en formation, en réunion d’équipe ou en assemblée. Suis les étapes avec ton propre Copilot, puis teste le résultat en direct à la fin.

Étape 1 — Décrire le squelette

Ouvre Copilot Chat et décris la plus petite version possible de ton idée. Sois précis sur ce qui doit apparaitre sur la page.

Copilot Chat
Crée une page web simple appelée "Sondage Éclair" avec une question et quatre boutons comme options de réponse.
Voici un point de départ : 
<!DOCTYPE html>
<html>
<head><title>Sondage Eclair</title></head>
<body>
  <h2>Qu'est-ce qui t'aiderait le plus ce trimestre ?</h2>
  <button>Des exemples corriges</button>
  <button>Plus d'exercices</button>
  <button>Des videos courtes</button>
  <button>Des seances de questions</button>
</body>
</html>

Enregistre ce fichier, ouvre-le dans ton navigateur en double-cliquant dessus. Tu as déjà une vraie page web, même toute simple.

Étape 2 — Demander la logique

Une page avec des boutons qui ne font rien n'est pas très utile. Demande à Copilot de faire compter les votes par les boutons.

Copilot Chat
Quand quelqu'un clique sur un bouton, enregistre un compteur de votes pour cette option dans le navigateur (localStorage), pour qu'il soit retenu si la page se recharge.
J'ai ajouté ce script en bas de ta page : 
<script>
  document.querySelectorAll("button").forEach((btn, i) => {
    btn.addEventListener("click", () => {
      let votes = JSON.parse(localStorage.getItem("votes")) || [0,0,0,0];
      votes[i]++;
      localStorage.setItem("votes", JSON.stringify(votes));
      alert("Merci pour ton vote !");
    });
  });
</script>

Teste : clique sur un bouton, recharge la page, clique encore — le compteur continue d'augmenter même si tu ne le vois pas encore. C'est la suite.

Étape 3 — Afficher les résultats

Demande maintenant à Copilot de remplacer ce simple alert() par quelque chose de visible pour tout le monde.

Copilot Chat
Au lieu d'une alerte, cache les boutons apres le vote et affiche chaque option sous forme de barre de pourcentage basee sur les votes actuels.
Bonne idée, c'est bien plus clair pour les votants. J'ai remplacé l'alerte par un petit affichage de résultats qui calcule la part de chaque option sur le total des votes et anime une barre pour la représenter. Je peux aussi ajouter un lien "revoter" pour réinitialiser cette démo, tu veux ?

Continue ainsi — une petite demande à la fois — jusqu'à ce que la page te plaise vraiment.

Étape 4 — Teste ce que tu viens de construire

Voici exactement l'application décrite ci-dessus, déjà construite et fonctionnelle. Clique sur une option et regarde les résultats apparaître : c'est ce que verront tes étudiants, collègues ou équipe une fois ta version publiée (prochaine leçon).

sondage-eclair.html
TipCommence toujours par une version minuscule qui fonctionne : l'étape 1 ci-dessus est déjà une page complete et fonctionnelle à elle seule.
À toi de jouerReconstruis toi-même exactement ce Sondage Éclair dans un nouveau fichier index.html, puis change la question et les quatre options pour coller à ton propre contexte : un sujet de cours, une question d'onboarding, une priorité budget, n'importe quoi de réel pour toi.

Leçon 4

Sauvegarder et publier avec GitHub

Une fois ta première version fonctionnelle, crée un dépôt (repository) sur GitHub et envoie-y ton code : c'est ce qu'on appelle un commit. À partir de là, ton travail est sauvegardé en ligne, versionné, et tu peux toujours revenir à une version précédente si quelque chose casse.

Active ensuite GitHub Pages sur ce dépôt : en quelques clics, ton application devient accessible via un simple lien, que tu peux partager avec tes étudiants ou tes collègues, sans aucun serveur à gérer.

TipUn dépôt GitHub, c'est aussi ta sauvegarde : même si ton ordinateur tombe en panne, ton projet est en sécurité.
À toi de jouerCrée un compte GitHub gratuit si tu n'en as pas, pousse ton Sondage Éclair dans un tout nouveau dépôt, et active GitHub Pages dessus.

Leçon 5

Tester et améliorer avec Copilot Chat

Fais tester ton application par un ou deux collègues, ou par toi-même en te mettant à la place d'un étudiant. Note chaque bug ou maladresse, puis décris-les un par un à Copilot Chat : « quand je clique sur ce bouton, rien ne se passe, corrige ça ».

Copilot peut aussi t'expliquer le code existant si tu ne le comprends pas encore complètement : demande-lui « explique-moi cette partie » avant de demander une modification.

TipUne seule correction à la fois : c'est plus facile de vérifier que ça fonctionne, et plus facile de revenir en arrière si besoin.
À toi de jouerEnvoie ton lien publié à deux collègues (ou camarades) et demande-leur de cliquer partout. Note chaque maladresse qu'ils rencontrent, puis corrige la première avec Copilot Chat.

Leçon 6

Améliorer le style et l'apparence

Une fois l’application utile, demande à Copilot d’améliorer la présentation : couleurs de l’établissement, espacements plus lisibles, texte plus accessible, meilleure hiérarchie visuelle. Tu peux aussi créer un petit Copilot Space avec des extraits de slides, une charte ou un exemple de ton pour garder les suggestions ancrées dans tes propres matériaux.

Pense aussi à l’accessibilité : contraste suffisant, texte lisible, labels clairs et boutons faciles à activer. Demande explicitement à Copilot de vérifier ces points avant publication.

À toi de jouerDemande à Copilot de restyliser ton Sondage Éclair avec deux couleurs de ton institution ou de ton équipe, puis vérifie le rendu sur ton téléphone aussi.

Leçon 7

Ajouter images, fichiers et documents

Beaucoup d'outils de cours ont besoin d'images, de PDF ou de documents à télécharger : un support de cours, un schéma, un formulaire. Demande à Copilot d'ajouter une zone d'affichage d'image ou un bouton de téléchargement, puis dépose simplement le fichier dans ton dépôt GitHub.

GitHub héberge aussi bien ton code que ces fichiers : pas besoin d'un autre outil pour stocker les ressources de ton application.

À toi de jouerAjoute une image ou un PDF téléchargeable (même un exemple factice) à ton Sondage Éclair, commit-le, et vérifie qu'il s'affiche bien une fois publié.

Leçon 8

Synthèse et vers le parcours Avancé

Tu sais maintenant transformer une idée de cours en application réelle : construire avec Copilot, sauvegarder et publier avec GitHub, tester, améliorer le style, ajouter des fichiers. Le réflexe le plus important : avance toujours par petites étapes que tu peux vérifier.

Le parcours Avancé prend le relais pour aller plus loin : connecter une vraie base de données, donner une mémoire durable à ton projet, et gérer ton code avec GitHub comme un vrai projet qui dure dans le temps.

À toi de jouerÉcris un README de trois lignes pour ton projet : ce qu'il fait, pour qui, et comment le rouvrir avec Copilot la prochaine fois.
