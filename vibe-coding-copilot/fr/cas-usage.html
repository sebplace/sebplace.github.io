🎓 Enseignantes et enseignants Copilot ChatSuggestions inline

Construire un quiz auto-corrigé en une seule séance

Tu veux un quiz que tes étudiantes et étudiants peuvent utiliser pour réviser un chapitre, sans passer par un outil externe payant.

  1. Ouvre Copilot Chat et décris ton quiz : « Crée une page HTML avec un quiz de 5 questions à choix multiple sur [sujet], affichant un score final. »
  2. Lis le code généré, teste-le dans ton navigateur, puis demande un ajustement précis à la fois, par exemple : « Ajoute une courte explication sous chaque question une fois qu'elle est répondue. »
  3. Une fois le résultat satisfaisant, demande à Copilot d'ajouter un bouton « recommencer le quiz ».

Résultat : Un quiz fonctionnel et personnalisé pour ton cours, prêt à publier.

Pour aller plus loin : Demande à Copilot de mélanger l'ordre des questions à chaque lancement.

🎓 Enseignantes et enseignants Copilot SpacesCopilot Chat

Ancrer une explication de schéma avec Copilot Spaces

Tu as des slides, un schéma scanné et des notes de tutorat, et tu veux un support numérique accessible plutôt qu’une image de plus dans un PDF.

  1. Crée un Space et ajoute l’image du schéma, le texte des slides concernées et une légende en langage clair.
  2. Demande à Copilot Chat de transformer ce matériau ancré en page HTML/CSS avec labels, texte alternatif et mini-glossaire.
  3. Publie la version validée sur GitHub Pages pour que la communauté étudiante y revienne hors cours.

Résultat : Une explication plus claire, réutilisable et ancrée dans tes propres supports.

Pour aller plus loin : Réutilise le même Space pour le prochain thème riche en schémas au lieu de réexpliquer tout le contexte.

🎓 Enseignantes et enseignants Copilot Chat

Générer des variantes d'exercices pour limiter la copie

Tu veux plusieurs versions d'un même exercice pour différents groupes d'étudiantes et étudiants.

  1. Donne à Copilot Chat un exercice existant et demande : « Génère 4 variantes de cet exercice avec des valeurs différentes mais la même difficulté. »
  2. Demande une grille de correction commune : « Ajoute une grille de correction expliquant chaque étape. »
  3. Demande à Copilot d'exporter le tout dans un seul document structuré.

Résultat : Plusieurs versions prêtes à distribuer, avec une correction cohérente.

Pour aller plus loin : Demande à Copilot de générer aussi une version accessible pour les lecteurs d'écran.

Apprendre à coder avec Copilot comme tuteur, pas comme béquille

Tu débutes en programmation et tu veux comprendre le code, pas seulement le copier.

  1. Écris d'abord une fonction simple toi-même, même incomplète.
  2. Demande à Copilot Chat : « Explique-moi ligne par ligne ce que fait ce code. »

Résultat : Une vraie compréhension du code, pas seulement un copier-coller.

Pour aller plus loin : Demande à Copilot un exercice légèrement plus difficile sur la même notion.

Transformer un seul brief de labo en trois variantes sûres

🎓 Enseignantes et enseignants Copilot cloud agentCopilot code reviewCopilot Spaces

Laisser le cloud agent de Copilot rafraîchir la FAQ d’un cours

La communauté étudiante pose chaque semaine les mêmes questions et tu veux mettre à jour la FAQ via des pull requests relisibles plutôt qu’à coups de copier-coller.

  1. Ouvre une issue du type « Ajouter les questions récurrentes de cette semaine dans la FAQ » et rattache le Space du cours si tu en utilises déjà un.
  2. Assigne l’issue à Copilot afin que le cloud agent prépare la mise à jour sur sa propre branche.
  3. Demande ensuite un Copilot code review sur la PR, relis le texte toi-même et fusionne la version approuvée.

Résultat : Une FAQ de cours qui s’améliore semaine après semaine sans transformer l’équipe pédagogique en équipe web.

Pour aller plus loin : Réutilise le même modèle d’issue après chaque bloc de cours pour faire de la FAQ un vrai actif pédagogique vivant.

Garder un mémoire ou un stage en mouvement avec Copilot Memory

Tu reviens chaque semaine sur le même projet et tu ne veux pas réexpliquer à chaque fois le contexte, la stack, les échéances et les contraintes.

  1. Conserve le contexte stable dans un flux Copilot compatible Memory et recopie les décisions importantes dans le README du dépôt.
  2. Demande à Copilot Chat la prochaine étape, un résumé d’avancement ou une passe de nettoyage sur le code courant.
  3. Commite chaque changement validé afin que l’historique reste lisible pour l’encadrement et l’équipe.

Résultat : Un rythme de projet plus régulier, avec moins de temps perdu à répéter le même contexte.

Pour aller plus loin : Memory aide à la continuité, mais la vraie source de vérité doit rester dans le dépôt.

🖥️ Services IT et numériques Agent skillsMode AgentCopilot CLI

Standardiser des scripts helpdesk répétitifs avec des Agent skills

Des techniciennes et techniciens résolvent le même ticket de nettoyage de comptes ou de collecte de logs de façons légèrement différentes, ce qui crée un risque inutile.

  1. Définis une Agent skill avec le patron de script approuvé, le format de log et les attentes de rollback.
  2. Demande ensuite au mode Agent ou à Copilot CLI d’adapter cette skill au ticket du jour plutôt que de repartir d’un shell vide.
  3. Relis le script ou le diff obtenu avant toute exécution dans l’environnement cible.

Résultat : Des automatisations internes plus répétables, avec moins de dérive par copier-coller entre collègues.

Pour aller plus loin : Versionne la skill sur GitHub afin qu’une seule mise à jour améliore le point de départ de toute l’équipe.

Garder des pages de politiques cohérentes avec des custom instructions

Les RH mettent souvent à jour des politiques, mais les titres, le ton, les avertissements obligatoires et les formulations inclusives dérivent d’une page à l’autre.

  3. Ouvre une pull request et utilise Copilot code review comme deuxième regard avant publication interne.

Créer un custom agent qui transforme des idées pilotes en briefs comparables

Plusieurs services proposent de petits outils internes en même temps, et la direction a besoin d’un brief comparable pour chaque idée avant d’arbitrer.

  1. Définis un custom agent qui doit toujours produire les mêmes rubriques : problème, publics, première version à faible risque, sensibilité des données et prochaine étape.

Produire les commentaires budgétaires mensuels dans un style partagé

L’équipe finances transforme le même export en commentaire mensuel, mais la formulation et les tableaux changent selon la personne qui s’en charge.
